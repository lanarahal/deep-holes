# قالب لایه‌های لباس خرگوش

پنل ادمین در **Admin → Rabbit styles** ست‌های کامل کاراکتر را مدیریت می‌کند. برای هر دسته (کلاه، لباس، عینک، دهان یا اکسسوری) یک PNG جداگانه انتخاب کنید.

## اندازه و چیدمان الزامی

- فایل باید **PNG با پس‌زمینهٔ شفاف** و اندازهٔ دقیق **۱۲۸۰×۱۶۰ پیکسل** باشد.
- هر فایل یک ردیف افقی از **۱۰ فریم ۱۲۸×۱۶۰** دارد و باید با ۱۰ فریم `assets/room/rabbit.png` هم‌خوان باشد: فریم‌های ۰ تا ۷ برای راه‌رفتن، فریم ۸ حالت ایستاده، فریم ۹ پلک‌زدن.
- جای اکسسوری را روی خرگوشِ همان فریم تنظیم کنید؛ هر فریم باید با فریم متناظر خرگوش هم‌تراز باشد. بخش‌های نامربوط را کاملاً شفاف نگه دارید.
- برای اینکه گزینهٔ «Tint» رنگ سفید/روشن را متناسب با رنگ تصادفی خرگوش تغییر دهد، رنگ‌مایهٔ اکسسوری را سفید یا خاکستری روشن، و خط دور را مشکی نگه دارید. با خاموش‌کردن Tint رنگ اصلی PNG حفظ می‌شود.
- فرمت PNG و حداکثر اندازهٔ آپلود هر لایه **۱۸۰ کیلوبایت** است. هر دسته اختیاری است، اما ست باید دست‌کم یک لایه داشته باشد.

قیمت هر ست فقط یکی از این دو ارز است: **🥕 Carrot Points** یا **◎ SOL شبیه‌سازی‌شدهٔ داخل همین نسخه**. این کیف‌پول محلی است؛ پرداخت واقعی آن‌چین یا همگام‌سازی اینترنتی در درایور فعلی وجود ندارد. برای فروش واقعی، کنترل مالکیت و پرداخت باید در سرور/برنامهٔ Solana اجرا شود.
